# GUI Screen Descriptions

Use this file while creating screenshots for your report.

## 1. Login Screen

Purpose: Let users sign in.

Visual points:

- Left gradient brand panel.
- Right rounded login card.
- Email/password fields.
- Register link for students.

Screenshot idea: Show the full login screen with UPES Lost and Found branding.

## 2. Register Screen

Purpose: Create a student account.

Fields:

- Full name
- SAP ID / roll number
- Email
- Phone
- Password

Screenshot idea: Keep the dialog centered over the login page.

## 3. Dashboard

Purpose: Give a quick campus property desk overview.

Sections:

- Lost Reports count
- Found Reports count
- Pending Claims count
- Matched Items count
- Claimed Items count
- Recent activity table
- Notifications panel

Screenshot idea: Login as admin to show richer data.

## 4. Report Item

Purpose: Submit lost or found item reports.

Fields:

- Report type
- Item name
- Category
- Location
- Date
- Description
- Contact details
- Storage location for found items
- Image path

Screenshot idea: Select `FOUND` to show the storage location field enabled.

## 5. Search & Matches

Purpose: Search reports and request claims.

Controls:

- Keyword
- Type filter
- Category filter
- Location filter
- Date range
- My reports only checkbox

Actions:

- View Details
- Possible Matches
- Request Claim

Screenshot idea: Select the Dell laptop row and click `Possible Matches`.

## 6. My Claims

Purpose: Student can track claim status.

Statuses:

- PENDING
- APPROVED
- REJECTED

Screenshot idea: Show a pending claim and explain admin verification.

## 7. Admin Reports

Purpose: Admin approves/rejects item reports.

Actions:

- Approve
- Reject
- Mark Claimed

Screenshot idea: Show multiple report statuses with colored badges.

## 8. Admin Claims

Purpose: Admin verifies claim proof.

Actions:

- Approve Claim
- Reject Claim

Screenshot idea: Approve a claim and show item status becoming `CLAIMED`.

## 9. Admin Users

Purpose: Manage student/admin accounts.

Actions:

- Make Admin
- Make Student
- Toggle Active

Screenshot idea: Show the role column and active column.
